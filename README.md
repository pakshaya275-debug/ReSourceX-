# ReSourceX ♻️

A unified surplus resource exchange platform connecting donors, community recipients, and administrators to reduce waste and route resources where they are needed most.

## 🚀 Features

- **Authentication & Role Management**: Sign in, register, and reset passwords for Donors, Recipients, and Administrators.
- **Donor Dashboard**:
  - Live statistics overview (Total, Available, Requested, and Allocated).
  - **My Resources**: Full inventory management with filtering and deletion.
  - **Incoming Requests**: Approve or decline recipient resource requests.
  - **Activity Log**: Chronological audit trail of all actions.
- **Recipient Dashboard**: Search, filter by category, view resource details, and submit requests.
- **Admin Dashboard**: System health monitoring, registered user moderation, and full resource oversight.
- **Responsive Modern UI**: Clean design system built with HTML5, CSS3, and JavaScript.
